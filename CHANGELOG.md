# Changelog

Sections after 0.2.0 are generated by `scripts/release.sh` from the `Changelog:` trailers
described in [CONTRIBUTING.md](CONTRIBUTING.md); 0.2.0 and earlier predate them and are
written by hand.

## [0.2.0] - 2026-10-03

### Added

- `gsichtl::badge`: a 12x12 round badge for groups, with a division, an emblem and sometimes a rim (58e0caf)

### Changed

- `Kind` has a new variant, `Badge`; an exhaustive `match` on `Kind` needs an arm for it. Every seed keeps its face, monster, nerd and crest from 0.1 (58e0caf)

## [0.1.1] - 2026-10-02

### Changed

- docs.rs builds with all features, so `Avatar::to_png` is documented. The first version published by the release workflow; the code is unchanged (93b96fb)

## [0.1.0] - 2026-10-02

### Added

- Deterministic pixel avatars from any seed: `face`, `monster` and `nerd` (8x8) and `crest` (10x10), rendered with `Avatar::to_rgba` and, with the `png` feature, `Avatar::to_png`. Extracted from griasdi, where it was developed as `crates/gsichtl` (5889c7e)
